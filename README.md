# BizMind AI — Dashboard v2

เว็บแดชบอร์ดสำหรับประกอบแฟ้มสะสมผลงาน (Portfolio) พัฒนาโดยใช้ HTML, CSS และ JavaScript ล้วน ไม่ต้องติดตั้ง Node.js หรือ API Key

## เริ่มใช้งาน

1. แตกไฟล์ ZIP และเปิดโฟลเดอร์ `bizmind-ai-v2` ใน VS Code
2. แนะนำติดตั้งส่วนขยาย **Live Server** แล้วคลิกขวา `index.html` → **Open with Live Server**
3. หรือดับเบิลคลิก `index.html` เพื่อทดลองเปิดด้วยเบราว์เซอร์ได้โดยตรง (การบันทึกข้อมูลบน `file://` อาจแตกต่างกันตามเบราว์เซอร์)
4. ครั้งแรกเว็บจะสร้าง **ข้อมูลตัวอย่าง** โดยอัตโนมัติเพื่อใช้ทดลองฟีเจอร์ต่าง ๆ
5. ไปที่หน้า **รายการธุรกรรม** เพื่อเพิ่มรายการจริง ดาวน์โหลด CSV ลบรายการ หรือโหลดข้อมูลตัวอย่างใหม่

## ไฟล์ในโครงการ

- `index.html` — โครงสร้างหน้าเว็บและฟอร์ม
- `styles.css` — ธีม Dark Business, การจัดวาง และ responsive บนมือถือ
- `app.js` — ระบบคำนวณ กราฟแบบ SVG, รายการธุรกรรม, การส่งออก CSV และการเก็บข้อมูล LocalStorage

## ฟังก์ชันที่ทำงานได้

- KPI รายรับ ค่าใช้จ่าย กำไร อัตรากำไร และการเปรียบเทียบช่วงก่อนหน้า
- ปรับช่วงเวลาของ KPI: 30 วัน, 90 วัน, 365 วัน และทั้งหมด
- กราฟเปรียบเทียบรายรับ/ค่าใช้จ่าย 6 เดือน และสัดส่วนค่าใช้จ่าย
- บันทึก ลบ ค้นหา กรองรายการและส่งออกข้อมูลเป็น CSV
- Smart Insights: คำแนะนำจากกฎที่อธิบายเหตุผลได้ และคะแนนสุขภาพธุรกิจแบบตัวอย่าง
- บันทึกข้อมูลเฉพาะในเบราว์เซอร์ (LocalStorage)
- รองรับหน้าจอมือถือและคอมพิวเตอร์
- พยายามย้ายข้อมูลจากคีย์ `bizmind-entries-v1` เดิมโดยอัตโนมัติ หากเปิดภายใต้ origin เดียวกันและยังไม่มีข้อมูล v2

## ข้อจำกัดสำคัญ

- **ยังไม่ได้เชื่อมต่อ AI API/โมเดล AI**: Smart Insights เป็นระบบวิเคราะห์ตามกฎ (rule-based) ไม่ควรอ้างว่าเป็น AI เชิงทำนายจริง
- **ข้อมูลตัวอย่างไม่ใช่ผลประกอบการจริง**: ต้องนำข้อมูลจากกิจการจริงที่ได้รับอนุญาตมาทดสอบก่อนนำเสนอสรุปเชิงธุรกิจ
- ข้อมูล LocalStorage ไม่ใช่ระบบฐานข้อมูลสำหรับใช้งานหลายเครื่อง ไม่ซิงก์ผ่านบัญชี และไม่ควรเก็บข้อมูลลูกค้าที่ละเอียดอ่อน
- CSS พยายามโหลด Google Fonts เมื่อออนไลน์ หากออฟไลน์จะแสดงฟอนต์ระบบแทน; JavaScript และกราฟไม่ต้องพึ่งไลบรารีภายนอก
- แนะนำตรวจสอบโจทย์และกติกา Track ของกิจกรรมอีกครั้งก่อนส่งประกวด

## วิธีเขียนคำอธิบายใน Portfolio

**ชื่อผลงาน:** BizMind AI — ระบบแดชบอร์ดวิเคราะห์ข้อมูลธุรกิจสำหรับผู้ประกอบการรายย่อย

**วัตถุประสงค์:** ช่วยให้ผู้ประกอบการติดตามรายรับ ต้นทุน และผลกำไรผ่านการแสดงผลข้อมูลที่เข้าใจง่าย

**เทคโนโลยี:** HTML, CSS, JavaScript, SVG และ LocalStorage

**บทบาทและทักษะ:** ออกแบบส่วนติดต่อผู้ใช้ พัฒนาการคำนวณพื้นฐาน สร้างกราฟและการสรุปข้อมูล ทดสอบระบบ และแยกข้อจำกัดของระบบต้นแบบ

ระบุบทบาทที่ลงมือทำและทดสอบจริงอย่างตรงไปตรงมา หากใช้เครื่องมือ AI ช่วยเขียนโค้ดให้ระบุเป็นกระบวนการทำงานร่วมกับ AI ตามกติกาของสถาบันและการแข่งขัน
